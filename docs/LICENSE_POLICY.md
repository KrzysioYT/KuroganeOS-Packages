# Package licensing and provenance policy

This repository currently does not declare one license that automatically applies to every third-party payload.

Each package should document:

- who owns/authors the payload;
- the payload/source license;
- where source can be found when applicable;
- whether redistribution through this repository is permitted;
- any required notices.

The optional `license=` manifest metadata is informational in Anvil v1; the current client does not enforce licenses.

Do not copy the KuroganeOS operating-system license onto unrelated third-party software unless that software is actually licensed under those terms. Likewise, do not publish binaries merely because they are freely downloadable elsewhere.

Official project policy may later adopt a repository-wide license for tooling/documentation separately from package payload licenses.
